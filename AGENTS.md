# AGENTS.md

## Назначение репозитория
Этот репозиторий используется как стартовая заготовка для экспериментов с playable-ads и агентными workflow.

## Правила для агентов
- Вносите небольшие, атомарные изменения.
- Перед коммитом проверяйте `git status` и список изменённых файлов.
- Старайтесь сопровождать изменения краткой документацией.

## Структура (план)
- `SKILLS.md` — перечень навыков/процедур для работы в репозитории.
- В будущем: каталоги с исходниками, ассетами и тестами.

## Чеклист перед PR
1. Убедиться, что изменения осмысленны и описаны.
2. Обновить документацию при необходимости.
3. Сделать коммит с понятным сообщением.
