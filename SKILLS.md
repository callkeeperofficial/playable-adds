# SKILLS.md

## Базовые навыки работы в этом репозитории

### 1) Навигация по проекту
- Используйте `rg --files` для быстрого просмотра файлов.
- Избегайте тяжёлых рекурсивных команд без необходимости.

### 2) Работа с Git
- Проверяйте текущую ветку: `git branch --show-current`.
- Перед коммитом просматривайте изменения: `git diff`.
- Пишите краткие и содержательные commit messages.

### 3) Документирование
- Любое новое правило фиксируйте в `AGENTS.md` или `SKILLS.md`.
- Держите формулировки короткими и проверяемыми.

### 4) Минимальные проверки
- Для документных изменений достаточно:
  - `git status --short`
  - `git diff -- AGENTS.md SKILLS.md`
