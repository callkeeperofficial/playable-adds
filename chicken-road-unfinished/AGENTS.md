# Chicken Road Unfinished Implementation Guide

This directory contains an imported standalone PixiJS playable game.

Read `../AGENTS.md` before implementing the game. Keep the project isolated in
this directory with its own Vite configuration, package files, source assets,
runtime assets, and production build output.

Add game-specific requirements here as the playable is defined.

Run the local development server on its reserved port:

```sh
npm run dev -- --host 0.0.0.0 --port 5175
```
