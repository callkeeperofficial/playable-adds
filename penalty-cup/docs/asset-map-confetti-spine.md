## Meaning

This asset is a full-screen confetti overlay effect.

The PNG only shows a few colored paper strips, but the Spine skeleton duplicates and animates them many times across a wide area.

It contains many repeated colored pieces:

```text
blue
green
pink
red
yellow
```

The skeleton has many `Pack` / `CV` / `CH` bones and many repeated confetti slots, which means the effect is generated by Spine transforms, not by a single static image.

## Hard Rule

Do not slice `confetti.png`.

Use Spine runtime.

Reason:

- the JSON controls hundreds of duplicated confetti pieces;
- movement, rotation, scale and fade are animated through bones/slots;
- manual slicing would lose the effect;
- PixiJS particle recreation is unnecessary if the Spine asset works.

## Runtime Usage

Use the same PixiJS Spine runtime as other Spine assets.

Preferred for PixiJS v8:

```text
@esotericsoftware/spine-pixi-v8
```

Pseudo-flow:

```ts
const confetti = Spine.from({
  skeleton: "confetti.json",
  atlas: "confetti.atlas",
});

confetti.state.setAnimation(0, "start", false);
confetti.state.addAnimation(0, "idle", true, 0);
```

Exact animation names must be validated from `confetti.json`.

If only `start` / `end` exist, use:

```ts
confetti.state.setAnimation(0, "start", false);
confetti.state.addAnimation(0, "end", false, 1.5);
```

Recommended behavior:

```text
big win: optional / light confetti
mega win: confetti enabled
epic win: confetti enabled
legendary win: confetti enabled
```

## Mobile Layout

This Spine skeleton is very wide:

```text
width ≈ 3427.23
height ≈ 208.26
```

Place it as a top/fullscreen overlay and scale to cover viewport width.

Suggested:

```ts
confetti.x = W / 2;
confetti.y = H * 0.05;
confetti.scale.set(W / confettiBounds.width);
```

Tune visually after loading because skeleton bounds are unusually wide and shallow.
